# Любовь Чайка — портфолио

Адаптивный сайт веб-дизайнера Любови Чайки на основе финальной 25-слайдовой презентации.

**Целевой адрес GitHub Pages:** https://lubochkachayka-ai.github.io/lyubov-chaika-portfolio/

## Что внутри

- Главная страница с восемью проектами и фильтрами по направлениям.
- Отдельные страницы кейсов и галереи с увеличением изображений.
- Разделы об авторе, образовании, программах и инструментах.
- Контакты: кликабельные телефон и e-mail, копирование почты.
- Финальная PDF-презентация для скачивания.
- Локальные шрифты и изображения, поддержка мобильных экранов и уменьшенной анимации.

## Публикация

GitHub Pages: ветка `main`, папка `/docs`. Сайт не требует сервера, базы данных или сторонних JavaScript-библиотек.

## Редактирование

Готовый сайт находится в `docs/`. Тексты и разметка доступны в HTML-файлах, стили — `docs/assets/style.css`, интерактивность — `docs/assets/app.js`.

Для повторной генерации HTML: `python scripts/build-site.py` (нужен Pillow). Редактируйте описания проектов и шаблоны в этом скрипте. Список проектов также сохранён в `projects.json`.

Проверка локальных ссылок и структуры: `npm run check`.

Подготовка копии для статического предпросмотра: `npm run build` (Node.js 18+). Установка npm-зависимостей не требуется.

## Материалы

Контент и проекты предоставлены автором. Новые варианты айдентики и фотореалистичные визуализации, подготовленные при работе над презентацией, показаны как концепции, а не как подтверждение реального внедрения. Работы имеют соответствующие подписи на страницах кейсов.

Шрифты Manrope и Cormorant Garamond используются по лицензии SIL Open Font License; тексты лицензий находятся в `docs/assets/fonts/`. Иконки программ взяты из Simple Icons и обозначают названия соответствующих инструментов.

Материалы портфолио не распространяются под открытой лицензией. Публичность репозитория не предоставляет права на их повторное использование.
